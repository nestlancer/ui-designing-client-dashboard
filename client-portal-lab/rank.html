Method in brief

Fixed rubric (weights 25/20/15/15/15/10, integer anchors 0–4, total = Σ weight×score÷4; critical-blocker cap at 49; ≤2.0 = practical tie). Every version is rendered in Chromium at 1440×1000, 768×1024, 390×844, dark, plus family task states; run through the same task script (first-screen, keyboard, core interaction, theme, demo honesty, mobile nav, axe-core); compared on seeded boards (which leak version IDs inside screenshots); then scored against the rubric before any prior winner claims are read. Full protocol record: review-evidence/review-manifest.json · data: review-evidence/scores.json · personas: review-evidence/personas.json · persona coverage matrix · method sources: review-evidence/RESEARCH.md.

Evidence limitations: Screenshots expose variant labels, so blinding was incomplete. Some pairwise entries are rubric-derived summaries, not independent judgments. Keyboard evidence samples the first 12 Tab stops; Shift+Tab, Enter, Space, Escape and all open/validation states were not exhaustively verified. Mobile-navigation selectors failed on some shells. No assistive-technology or WCAG conformance audit was performed.
