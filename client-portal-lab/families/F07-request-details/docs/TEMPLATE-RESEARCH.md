## Takeaways mapped to V1–V5

- **States as sentences** (New → In review → Waiting → Resolved) → V3 Stepper Process.
- **Axis / markers / timestamp** → V1 Timeline-led (vertical spine with time + marker).
- **Progressive disclosure** → V2 Dense Ledger (all changes in one row set); V4 Minimal Decision (the one question).
- **Status transitions Before/During/After** → V5 Action-Led (the decision that moves it forward).

- AI copilots / auto-summaries (no AI endpoint exists).
- Rainbow status colours (locked single-blue scheme; status uses the locked `--success-600`/`--brand-500` tokens).
