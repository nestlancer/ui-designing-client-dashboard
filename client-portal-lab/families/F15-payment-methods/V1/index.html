How adding a method works

  1. Saved automatically. When you pay through Razorpay, the method you used is saved to your account with its card network and last four digits only.
  2. Manual token entry is not supported. There is no field for a card number, CVV or UPI handle in the portal — the gateway collects those, never this page.
  3. One default at a time. The default method is preselected at checkout; you can change it here once a method exists.

This page loads from GET /payments/methods. An empty list is a valid, successful response — not an error — so it is shown as an empty state rather than a failure block.
