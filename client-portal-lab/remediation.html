Implementation and evidence boundaries

The recurring repairs live in shared/workspace-layout.css, loaded after each page’s variant styles. All 100 pages have a matching data-family opt-in; only the few version-specific exceptions use data-version. The original shared tokens and base stylesheet were not rewritten.

Foreground ink is separated from filled-control colour, mobile breadcrumbs shrink before controls do, local scrolling stays keyboard-accessible, and compact visual labels retain accessible names. Version layouts, escaped fixtures, locked counts and explicit demo boundaries are preserved.

Limits: this is Chromium regression evidence, not a new heuristic score, user study, screen-reader audit, cross-browser certification or proof of production backend behaviour. Default states and selected repaired interactions were checked, not every possible modal/state combination. Unconfirmed fixture spelling and inconclusive historical probes were not silently converted into invented product facts.

No new screenshots were generated and none of the existing historical screenshots were deleted. The two new JSON evidence files total approximately 123 KB; browser dependencies and scratch output are ignored rather than added to the repository.

Reproduce the read-only checks

Serve the repository root on port 8130. In a separate terminal, install the pinned test dependencies and a Playwright-compatible Chromium browser:

# Repository root, separate terminal:
python3 -m http.server 8130 --bind 0.0.0.0

# Test terminal:
cd client-portal-lab/review-evidence/tooling
npm ci
npx playwright install chromium
QA_OUTPUT=../remediation-layout.json node verify-remediation.mjs
QA_OUTPUT=../remediation-interactions.json node verify-interactions.mjs

Use QA_BASE_URL for another static server address. Both runners accept optional family IDs, such as F03 F04; omit them for the final 100-page run. Keep partial-run output separate from the full evidence above.

The Arena run used CHROMIUM_PATH=/tmp/chromium and LD_LIBRARY_PATH=/tmp/al2023/lib for its packaged Chromium. These runtime files are temporary, not repository dependencies. The test scripts never edit HTML, CSS, application JavaScript or ranking scores.
