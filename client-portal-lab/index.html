Serve from the repository root: python3 -m http.server 8130, then open /client-portal-lab/. Opening the files directly with file:// works for individual pages but breaks the shared stylesheets in some browsers.

No browser automation was available while this lab was assembled, so nothing here claims a screenshot comparison. What was checked: HTML tag balance, JavaScript parse for every page, resolvable internal links, no external requests, and one shared token file.
